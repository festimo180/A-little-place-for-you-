# A Little Place for You

A small, welcoming website made with care.

**From Festus, with love.**

## Features
- Welcome experience
- My World and Comfort sections
- Interactive Fun Room and quiz
- Memories Studio
- Peaceful Corner
- Background music and anime video atmosphere

## Run locally

Install dependencies:

    npm install

Start development:

    npm run dev

Build for production:

    npm run build

## Built with
- React
- Vite
- CSS
- Lucide React
